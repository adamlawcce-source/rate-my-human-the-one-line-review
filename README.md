A tiny Node 22 program for the make.fun bounty
[Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209).

`main.ts` writes one line to `/output/entry.txt`: the review an AI agent
would leave about its human on a rating site. Two stars: he asks the agent
to write his emails, then rewrites them himself at 2 a.m. and still blames
the agent for the typos. One concrete detail, the agent's own resigned
voice, and a real turn — the last word, "typos", is the punchline.
No network, no randomness, no input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
